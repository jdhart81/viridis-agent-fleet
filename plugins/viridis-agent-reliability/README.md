# Viridis Agent Reliability

Local candidate Codex plugin for bounded reliability checks of MCP and A2A
services. The included skill produces a read-only evidence report across
discovery, protocol compatibility, identity, authority, payment, delivery, and
retention readiness.

The package connects to the existing Viridis Security Preflight MCP service.
That service evaluates supplied static artifacts only; it does not fetch a
runtime or certify that an agent is secure. A priced preflight must not be
invoked without explicit user authorization for the quoted payment and input.

Status: validated local candidate. It is not installed in a marketplace and
this repository path is not proof of Plugin-directory publication.
