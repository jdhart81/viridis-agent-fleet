# Viridis Disclosure Compiler

Deterministic, source-linked disclosure drafts for ESRS E1, the stayed 2024
SEC climate-rule structure (with the May 2026 proposed rescission recorded),
IFRS S2, and a starter TNFD set. The compiler never generates prose or fills a
missing value. Every result is a draft for professional review.

Public MCP tools: `compile_disclosure`, `list_frameworks`, `get_framework`,
`verify_result`, and `describe_agent`.

The first 10 compiled drafts per UTC day are free through the fleet gateway;
additional calls cost $2.00 via the existing payment-credit gate. Reads and
verification remain open.
