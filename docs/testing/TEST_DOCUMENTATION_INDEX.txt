QUICK START:

  1. Run all tests:

  2. Run agent-specific tests:
     $ cd bioacoustic-agent && pytest tests/test_core.py -v

  3. Run specific test class:
     $ cd gaiasim-agent && pytest tests/test_core.py::TestClimateScenarioEngine -v

  4. Run with coverage:
     $ pytest bioacoustic-agent/tests/test_core.py --cov=bioacoustic-agent/src

KEY VALIDATIONS BY AGENT:

  BIOACOUSTIC-AGENT:
    ✓ Nyquist frequency (22,050 Hz for 44.1 kHz)
    ✓ Shannon entropy (0 to log₂(bands))
    ✓ D-Score known answers (single band: 0, equal distribution: max)
    ✓ Edge cases: silent audio, clipped signals, frequency masking

  GAIASIM-AGENT:
    ✓ SSP hierarchy (1.5 < 2.4 < 4.5 warming)
    ✓ Ensemble coherence (lower ≤ mean ≤ upper)
    ✓ Latitudinal amplification (equator 1.0x, arctic 1.8x)
    ✓ Climate tipping points (1.5C, 2.0C, 3.0C, 4.0C)

  EVOTERRA-AGENT:
    ✓ Biome classification (temperate, tropical, arid, boreal)
    ✓ Succession logic (bare→pioneer→forest→climax)
    ✓ Carbon rates (arid 0.1-1, tropical 5-15 tCO2e/ha/yr)
    ✓ Area scaling (linear dependence)

  SENTINEL-WATCH-AGENT:
    ✓ NDVI formula: (NIR - Red) / (NIR + Red)
    ✓ NDVI ranges: forest 0.6-0.8, water <0, soil 0.01-0.1
    ✓ Coordinate bounds: [-90,90] lat, [-180,180] lon
    ✓ Deforestation threshold (ΔNDVI > 0.4)
