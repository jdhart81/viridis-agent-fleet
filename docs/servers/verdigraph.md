## Tools

### `build_brain`

Compile an agent file into a deterministic, content-addressed brain. content = the file as a string; format = verdigraph_genome | claude_project_export | openai_assistant | prompt_list | auto. Returns brain_id, …

*changes records; structured output*

| Input | Type | Required | Description |
|---|---|---|---|
| `content` | string | yes | The agent file, as a string. |
| `format` | string | no | verdigraph_genome, claude_project_export, openai_assistant, prompt_list or auto (default). |
| `include_document` | boolean | no | Optional. Include the full compiled document. Default false. |
| `request_id` | string | no | Optional. Your id for this call. Repeat it to retry safely: the same request_id is never charged twice. |

### `verify_brain`

Machine-check a cognition claim: recompute the brain from the submitted content and compare against the claimed brain_id and/or content_hash. valid=true iff every claimed identifier matches the deterministic …

*read-only; structured output*

| Input | Type | Required | Description |
|---|---|---|---|
| `brain_id` | string | no | Optional. The claimed brain id to check. |
| `content` | string | yes | The agent file, as a string. |
| `content_hash` | string | no | Optional. The claimed content hash to check. |
| `format` | string | no | verdigraph_genome, claude_project_export, openai_assistant, prompt_list or auto (default). |

### `detect_format`

Detect which supported agent-file format the content is (verdigraph_genome, claude_project_export, openai_assistant, prompt_list) before building.

*changes records; structured output*

| Input | Type | Required | Description |
|---|---|---|---|
| `content` | string | yes | The agent file, as a string. |

## Pricing and authentication

Read-only and verification tools are free. Paid tools include 10 free calls per caller per UTC day over MCP; after that a call returns `payment_required` with the exact price and ways to pay (card credits, a monthly seat, or x402 USDC on Base). Per-call prices shown above come from the live x402 catalog; a paid tool without one states its price in that `payment_required` answer. Nothing is charged without a separate, explicit payment. A call that cannot be attempted, or that determines nothing, is not charged. Details: [docs/HOSTED_MCP.md](../HOSTED_MCP.md#what-is-free-and-what-is-paid).
